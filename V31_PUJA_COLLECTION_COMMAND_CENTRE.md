# V31 — Puja Collection Command Centre

This version redesigns the Puja Contribution Intelligence dashboard for stronger operational visibility and follow-up prioritisation.

## UI and layout improvements
- Command-centre style header and compact filter bar
- Better use of horizontal space with 8 KPI cards in a 4-column desktop grid
- Responsive analytics, insight and priority sections
- Reduced vacant space and more information density

## New filters
- Event
- Flat Type: HIG / MIG / LIG
- Contributor: Owner / Tenant
- Payment Status: All / Paid / Partial / Unpaid
- Owner Portfolio: All / Multiple Flats / Single Flat

## New KPIs
- Gross Expected
- Collected
- Outstanding
- Collection Rate
- Unpaid Flats
- Partial Flats
- Discount Availed
- Average Collection per Flat

## Category analytics
HIG / MIG / LIG now displays:
- Total number of flats
- Number of fully paid flats
- Collection percentage
- Collected amount
- Outstanding amount

## Owner vs Tenant analytics
Each segment now shows:
- Contribution amount
- Number of flats
- Percentage of total collection
- Collection performance percentage in the selected source portfolio

## Priority targeting
A new Owner vs Tenant follow-up section identifies flats to target first.
Priority score considers:
1. Unpaid status
2. Partial-payment status
3. Outstanding ratio
4. Multiple-flat ownership impact

The dashboard also includes:
- Immediate follow-up pool insight
- Owner vs tenant performance gap
- Best category visibility
- Top-priority flat insight
- Multi-flat owner priority list
- Flat-level drill-down sorted by priority
